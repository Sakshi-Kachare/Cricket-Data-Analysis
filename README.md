# 🏏 Cricket Data Analysis Using Python



## 📌 Project Overview



This project focuses on analyzing cricket player performance data using Python. It explores batting statistics, player career records, country-wise performance, and career length through data analysis and visualization.



The project uses Python libraries to clean, process, analyze, and visualize cricket data.



## 🎯 Project Objectives



\- Analyze cricket players' batting performance.

\- Explore player statistics across different countries.

\- Calculate average career length.

\- Analyze batting strike rates.

\- Identify top players based on highest innings scores.

\- Understand relationships between career length, batting average, and strike rate.

\- Create meaningful data visualizations.



## 🛠️ Technologies \& Libraries Used



\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



## 📂 Dataset Information



The dataset contains cricket player statistics with details such as:



\- Player Name

\- Country

\- Matches Played

\- Innings

\- Runs

\- Highest Innings Score

\- Batting Average

\- Strike Rate

\- Hundreds (100s)

\- Fifties (50s)

\- Ducks (0s)

\- Fours (4s)

\- Sixes (6s)

\- Career Start Year

\- Career End Year



\*\*Dataset Size:\*\* 62 records and 15 original columns.



## 🧹 Data Cleaning \& Preprocessing



\- Imported cricket data using Pandas.

\- Renamed columns for better readability.

\- Checked missing and duplicate values.

\- Handled missing values using `fillna()`.

\- Split career span into start year and end year.

\- Extracted player names and country information.

\- Removed unnecessary characters from numeric columns.

\- Converted columns into appropriate data types.

\- Created a new column named `Career\_Length`.



## 📊 Data Analysis Performed



1\. Average career length of cricketers.

2\. Average batting strike rate of players with more than 10 years of career.

3\. Number of cricketers who started playing before 1960.

4\. Maximum highest innings score by country.

5\. Number of hundreds, fifties, and ducks by country.

6\. Top 10 players based on highest innings score.

7\. Top 10 cricketers based on career length.

8\. Players with the most hundreds, fifties, and ducks.

9\. Cricketers grouped by career start year.



## 📈 Data Visualizations
